# Bill of materials -- Chapter 1

Receive-only FM relative-strength lab.

| Item | Notes |
| --- | --- |
| RTL-SDR Blog V4 or equivalent RTL2832U dongle | USB software-defined radio receiver |
| Telescopic antenna | Often bundled with the dongle; extend for VHF FM |
| USB cable | Usually included; prefer a short, well-shielded cable |
| Host laptop | Windows with SDR++, or Linux/macOS with GQRX (or SDR++) |
| Notebook | Log frequency, gain, antenna position, relative peak reading |

No transmitter. No amplifier between the antenna and the dongle for this chapter.
