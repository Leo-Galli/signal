# Bill of materials -- Chapter 9

Minimal WBFM receive flowgraph in GNU Radio (receive-only).

| Item | Notes |
| --- | --- |
| Host computer | Runs GNU Radio Companion and the generated flowgraph |
| GNU Radio install | Current 3.10.x-class install with Companion; follow project docs for your OS |
| RTL-SDR Blog V4 or equivalent RTL2832U dongle | Required for the live graph; optional if you only run the file-source graph |
| Antenna | Telescopic or VHF antenna suited to broadcast FM |
| Optional IQ file | Complex float clip from Chapter 4 for file-source practice |

No transmitter. Close other SDR apps before the live graph claims the stick.
