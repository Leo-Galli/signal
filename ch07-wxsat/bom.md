# Bill of materials -- Chapter 7

Receive-oriented VHF weather-satellite practice (APT history, Doppler, optional live path).

| Item | Notes |
| --- | --- |
| RTL-SDR Blog V4 or equivalent RTL2832U dongle | USB software-defined radio receiver |
| VHF antenna suited to ~137 MHz | Turnstile, V-dipole, or QFH-class; telescopic whip is a weak indoor start only |
| Host computer | Pass prediction browser + decoder / companion tools |
| Optional audio path | Virtual cable or WAV recorder if your decoder expects audio |
| Notebook | Pass times and artifact notes before filling JSON |

No transmitter. Classic NOAA-15/18/19 APT is decommissioned (2025); live work needs an active satellite your tools support, or the companion practice WAV for offline grayscale output.
